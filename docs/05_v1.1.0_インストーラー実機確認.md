# v1.1.0 インストーラー実機確認手順

## 事前条件

- Windows 11 x64の使い捨てVMまたはWindows Sandboxを使用する。
- VMのスナップショットを取得する。
- `WebP-Converter-Setup-1.1.0.exe` と `.sha256` を同じフォルダへ置く。
- 現在の開発PCで実施する場合は、インストール、アンインストール、レジストリ変更の承認を先に得る。

## 自動テストとして実施する項目

```powershell
npm ci
npm test
npm run self-check
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1
npm test
```

確認内容:

- 変換処理の既存テスト
- 製品バージョンの整合性
- リリースマニフェストの全ファイルSHA-256
- Inno Setupの権限、固定パス、OS、アーキテクチャ、HKCU登録設定
- 同梱Node.jsとSharpによる変換
- EXE名、ファイルバージョン、未署名状態、配布SHA-256

## 1. 新規インストール

1. SHA-256を確認する。
2. EXEをダブルクリックする。
3. UAC昇格画面が出ないことを確認する。
4. `%LOCALAPPDATA%\Programs\WebPFolderConverter` に配置されることを確認する。
5. 「インストールされているアプリ」に1件だけ表示され、バージョンが1.1.0であることを確認する。
6. HKCUの `Software\Classes\Directory\shell\WebPFolderConverter` だけが登録されていることを確認する。

## 2. v1.0.0からの更新

1. VMを初期状態へ戻す。
2. GitHub Release v1.0.0のZIPを使い、公開手順どおりにv1.0.0を導入する。
3. v1.0.0で右クリック変換が成功することを確認する。
4. v1.1.0 EXEを実行する。v1.0.0の手動アンインストールは行わない。
5. 更新後も右クリック変換が成功することを確認する。
6. Installed Appsがv1.1.0の1件だけであることを確認する。
7. `%LOCALAPPDATA%\Programs\.WebPFolderConverter.v1.0.0-backup` と移行状態JSONが残っていないことを確認する。

## 3. 変換機能

日本語と空白を含むフォルダにPNG、JPG、JPEG、既存WebP、サブフォルダ内画像を用意し、次を確認する。

- 直下のPNG/JPG/JPEGだけが変換される。
- 元画像と既存WebPのハッシュ、更新日時が変わらない。
- サブフォルダは処理されない。
- 透過、EXIF Orientation、結果ダイアログ、ログが正常である。
- PATHからNode.jsを除外しても同梱ランタイムで動作する。

## 4. アンインストールと再インストール

1. Windowsの設定からアンインストールする。
2. 右クリックメニューキーとInno Setup管理ファイルが削除されることを確認する。
3. テスト画像、生成済みWebP、案件ファイル、変換ログが残ることを確認する。
4. v1.1.0を再インストールし、右クリック変換が再び成功することを確認する。

## 5. 失敗時の安全性

VMのスナップショットへ毎回戻して、次を個別に確認する。

- EXEの1バイトを変更し、内蔵整合性検査でインストール開始前に拒否されること。
- ウィザード中およびファイル配置中にキャンセルし、既存バージョンが利用可能であること。
- v1.0.0の一部ファイルをロックまたは書き込み拒否にして更新を失敗させ、旧ファイルと右クリック登録が復元されること。
- 更新途中でVMを強制停止し、再起動後にセットアップを再実行すると未完了移行が復旧されること。
- 正規v1.0.0ではないフォルダまたは別のコマンドを指す同名レジストリキーがある場合、変更前に中止すること。

各ケースで元画像、既存WebP、案件ファイルのSHA-256を前後比較する。セットアップログと移行状態を保存し、問題がなければVMを破棄する。
